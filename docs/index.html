Bis die Zeile getippt ist, ist der Pull gelaufen. By the time the line is typed, the pull is over.

Im Schlüsselstein ist die Ansage oft wichtiger als die Rotation – nur hat man beim Tippen beide Hände am Charakter. Tactical Callout Dock legt eine kleine Leiste auf den Bildschirm: ein Klick, und die Ansage steht im richtigen Kanal, der Totenschädel sitzt auf dem Ziel und der Ping ist gesetzt. In a keystone the callout often matters more than the rotation – but typing needs both hands. Tactical Callout Dock puts a small bar on your screen: one click, and the callout is in the right channel, the skull is on the target and the ping is placed.

Zum Ausprobieren: eine Leiste wie im Spiel Try it: the dock as it looks in game

Reiter wechselt die Rolle, Klick auf einen Knopf zeigt, was er auslösen würde. The tabs switch role; clicking a button shows what it would trigger.

Die Leiste oben ist eine Nachbildung in HTML – im Spiel trägt sie die Symbole von Blizzard und lässt sich frei verschieben, drehen und in der Größe ändern. The dock above is an HTML mock-up – in game it carries Blizzard's own icons and can be moved, rotated and resized freely.

Was es tutWhat it does

Drei Aktionen auf einem KnopfThree actions on one button

Chatnachricht, Zielmarkierung und Ping – einzeln oder zusammen, ausgelöst durch einen einzigen Klick. Die Markierung kommt zuerst, damit der Totenschädel schon sitzt, wenn die Gruppe hinsieht. Chat message, raid marker and ping – separately or together, from a single click. The marker goes first, so the skull is already in place when the group looks.

Drei Rollenprofile, fertig bestücktThree role profiles, ready to use

Tank, Heiler und Schaden mit je acht Ansagen aus dem echten Schlüsselstein-Alltag. Umschalten über die Reiter an der Leiste oder /tcd tank. Tank, healer and damage, eight callouts each, taken from actual keystone runs. Switch with the tabs on the dock or /tcd tank.

Editor im SpielIn-game editor

Knöpfe anlegen, bearbeiten, umsortieren, löschen – ohne eine einzige .lua anzufassen. Mit Vorschau: Wer %t tippt, sieht direkt darunter, welcher Name gleich im Chat steht. Add, edit, reorder and delete buttons without touching a single .lua file. With a preview: type %t and the name that will appear in chat is shown right below.

Es arbeitet auch im KampfIt works during combat

Kein Knopf wirkt eine Fähigkeit – deshalb braucht keiner eine geschützte Vorlage. Profilwechsel, Größe, Ausrichtung und selbst das Verschieben funktionieren mitten im Pull. Es gibt keine Zeile, die etwas „später nachholt“. No button casts a spell, so none needs a secure template. Switching profiles, size, direction and even dragging all work mid-pull. Not one line defers work “until after combat”.

Der Kanal stimmt von selbstThe channel is chosen for you

Hier liegen die meisten Ansage-Addons daneben: Ein fest auf RAID gestellter Knopf sendet in einer Fünfergruppe nichts – und meldet das auch nicht. Man drückt, sieht nichts und hält das Addon für kaputt. Dieselbe Taste geht deshalb hier je nach Lage woandershin. This is where most callout addons get it wrong: a button hard-wired to RAID sends nothing in a five-player group – and does not say so. You press it, see nothing, and assume the addon is broken. So the same key goes somewhere different depending on where you are.

Auch fest eingestellte Kanäle fallen geordnet zurück, statt ins Leere zu senden: Eine Schlachtzugswarnung ohne Anführerrecht wird zu normalem Schlachtzugschat, PARTY in einer Instanzgruppe zu INSTANCE_CHAT. Und wenn eine Ansage dadurch in /sagen landet, sagt das Addon es einmal. Fixed channels fall back in order too, rather than sending into the void: a raid warning without lead becomes ordinary raid chat, PARTY inside an instance group becomes INSTANCE_CHAT. And if a callout ends up in /say because of it, the addon tells you once.

Zu den Addon-RegelnOn the addon rules

Es automatisiert nichts.It automates nothing.

Kein Timer, der etwas sendet. Kein Spielereignis, an dem eine Nachricht hängt. Keine Wiederholung, keine Warteschlange. Eine Ansage entsteht ausschließlich dort, wo ein Mensch auf einen Knopf drückt – das ist auch die Bedingung, an die Blizzard die Ping-Schnittstelle knüpft. No timer that sends anything. No game event a message hangs on. No repetition, no queue. A callout only ever happens where a human presses a button – which is also the condition Blizzard attaches to the ping API.

Kein Knopf wirkt eine Fähigkeit.No button casts a spell.

Das ist keine nachträgliche Einschränkung, sondern die Entwurfsentscheidung, aus der die Kampftauglichkeit erst folgt: Chatnachricht, Zielmarkierung und Ping sind ungeschützte Funktionen. Not a restriction bolted on afterwards, but the design decision the combat behaviour follows from: chat message, raid marker and ping are all unprotected functions.

Es kommt ohne Fremdbibliotheken aus.It ships without external libraries.

Kein Ace, kein LibDataBroker, kein LibDBIcon. Der Knopf an der Minikarte ist von Hand gebaut. Dafür findet keine Sammelleiste wie Titan Panel dieses Addon – das ist der Preis, und er steht so auch im README. No Ace, no LibDataBroker, no LibDBIcon. The minimap button is built by hand. The price is that brokers like Titan Panel will not find this addon – that trade-off is stated in the README too.

InstallierenInstall

  1. Das Archiv herunterladen und entpacken. Download the archive and unpack it.

  2. Den Ordner TacticalCalloutDock nach World of Warcraft\_retail_\Interface\AddOns\ legen. Put the TacticalCalloutDock folder into World of Warcraft\_retail_\Interface\AddOns\.

  3. Im Spiel /tcd tippen. Wenn etwas nicht stimmt, sagt /tcd doctor, was. Type /tcd in game. If something is off, /tcd doctor says what.
